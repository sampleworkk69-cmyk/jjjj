# Bihar Charitra website

A responsive React + Vite editorial website for Bihar Charitra, styled in warm beige and burgundy.

## Run locally
1. Install Node.js (18+ recommended).
2. In this folder run `npm install`.
3. Run `npm run dev` and open the local URL Vite prints.

## Build
`npm run build` creates the production website in `dist/`.

## Publish on GitHub Pages
1. Create a GitHub repository and upload the contents of this folder.
2. In `package.json`, add `"homepage": "https://YOUR-USERNAME.github.io/YOUR-REPOSITORY"` if you use the `gh-pages` deployment script.
3. Run `npm install`.
4. Run `npm run deploy`.
5. In GitHub → Settings → Pages, select the `gh-pages` branch if it is not selected automatically.

Alternatively, use GitHub Actions to deploy the `dist` folder.
